# Curated Legal Sources

This directory contains curated legal materials for the Bankruptcy
Inheritance Issue Mapper.

## Directory structure

- 01_Primary_Legislation: selected Bankruptcy Act 1966 (Cth) provisions.
- 02_AFSA_Professional: relevant AFSA professional practice guidance.
- 03_AFSA_Client_Guidance: relevant AFSA public-facing guidance.

## Source preparation

Each legal source must be saved as a UTF-8 .md or .txt file with
the metadata required by the application:

- source_id
- title
- source_type
- provision_or_pinpoint
- version_date

Every source_id must be unique across this directory.

Preserve the original wording, paragraph numbers, qualifications
and relevant context. Record the actual source version where known.

AFSA guidance must be labelled as guidance, not legislation or a case.

## Maintenance

Check source accuracy, currency and relevance before use.
Rebuild the application's legal index after adding or changing sources.

README.md files contain documentation only and are excluded from
the application's legal retrieval index.
